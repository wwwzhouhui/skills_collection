按 `env-setup` skill 跑一遍环境体检。

- 附加参数 (可选): `$1` — 传 `--fix` 表示体检后直接把**可自动装**的项装上 (pip 包, 默认走清华镜像); 不传则只体检 + 列出要装什么。

要求:

1. 先跑 `env_doctor.py` (Bash timeout ≥ 120s — 出网被挡时它要先把超时耗完才能给结论), 不要凭记忆预判缺什么。
2. 按打印顺序处理; 标 `[未探测]` 的项不要照着装, 先修它的前置再重跑体检。
3. **系统级软件不要替用户装**: ffmpeg、中文字体只报"要什么" + 脚本给的本平台示例命令, 让用户自己执行 —— 各人机器上的装法和权限都不同。**卸包更不许自动做** (opencv GUI 版可能是别的项目装的)。
4. 装不动先换镜像再谈代理: pip 默认已带清华源; ffmpeg 在 mac 上要先 `HOMEBREW_BOTTLE_DOMAIN`, 任何平台都可以用 conda-forge 清华镜像绕开。但改全局配置 (`pip config set global.index-url`) 前先问用户 —— 那影响他机器上所有项目。
5. 标 `·` 的是本平台不适用, 不是缺口; 标 `只降级不致命` 的 (TTS 凭据、磁盘余量) 不阻塞纯剪辑任务。
6. 字体那项要看清楚: 打印了路径**也可能是缺口** —— 若结论说该字体 cmap 无中文, 那烧出来是豆腐块而 ffmpeg 退出码 0, 必须当缺失处理 (装 Noto CJK 或设 `VE_FONT_DIRS`)。
7. 收尾报告说**能力**而非包名: 哪些工具现在可用、哪些不可用 (例: "ffmpeg 无 libass → 字幕烧录不可用, recap 交不了"), 用户还需要做什么。

只做环境, 不要顺手开始剪辑任务。
