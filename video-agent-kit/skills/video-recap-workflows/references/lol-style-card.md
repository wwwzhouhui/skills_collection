# 电竞解说文风卡(LOL)——只学手法,不抄内容

给 lol-recap 写解说词时的语感参考。目标:像一个懂球的解说,激情、口语、干净地把这局讲成一个故事。

## 语气
- 口语、短句、有节奏;该燃的时候燃,运营铺垫时压住。
- 三档情绪只靠语速+响度:铺垫(tier0)平稳交代;拔高(tier1)节奏起来;爆发(tier2)呐喊,短促有力。

## 术语(自然用,别堆砌)
滚雪球 / 节奏 / 开团 / 收掉 / 秒了 / 越塔强杀 / 反杀 / 换掉 / 一波带走 / 经济差 / 视野 / 抓机会 / 拿到大龙 / 龙魂 / 先锋 / 破高地 / 上高地 / 团灭 / carry。

## 句式示范(手法,不是照抄)
- 铺垫桥接:"开局双方还在对线,但EDG的打野已经绕到了下路——"
- 拔高:"这一波抓死了对面AD,EDG的雪球开始滚起来。"
- 呐喊(钉击杀秒,hard):"绕后!一个大招三个人!团灭了!"
- 事件后点评:"5比0,这局的节奏彻底到了EDG手里。"
- 转折:"就在所有人以为稳了的时候,TT偷了大龙——"
- 收尾扣题:"从一血到终结,EDG用一场教科书式的滚雪球拿下第一局。"

## 禁忌
- 不写"镜头/画面/我们看到";不剧透后面的拍;不自造选手名/英雄名(解说轴没有就不用)。
- 呐喊不靠拉高音调(听着像换人),只靠语速响度。
- 画面细节(血条/表情/具体走位)没看帧就别写死。
