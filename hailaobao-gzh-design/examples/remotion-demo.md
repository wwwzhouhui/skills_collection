# TOPIC | 用代码做视频 | WorkBuddy + Remotion 上手指南

今天聊一个非常适合剪辑师和内容创作者折腾的工具组合，**WorkBuddy + Remotion**。

剪辑久了，经常会遇到一种很尴尬的需求。

片子主体已经差不多了，只缺一段五秒钟的数据动画，或者一张人物卡片，再加一条能跟着镜头移动的路线。

直接套现成模板，风格也不一定合适。打开 AE 做动画，又特别费时间。

> Remotion + WorkBuddy 就能很好地解决这个问题。

## 01 | Remotion 到底是什么

Remotion 是瑞士公司 Remotion AG 推出的一套源代码公开的视频制作工具。可以把它理解成一台**用代码生成视频的机器**，电脑会按照代码要求，一帧一帧生成画面，最后合成视频。

我们只需要安装 Remotion 相关的 Skill 后，再提出视频需求，WorkBuddy 等 Agent 就会按照说明运行官方命令，自动下载 Remotion、创建工程并编写动画代码。

画面里的文字、图形、图片、音频、数据和镜头变化，都可以**按照时间精确安排**，最后再渲染成普通的视频文件。

它和我们现在常用的 AI 视频有很大区别。

生成式 AI 视频更擅长人物、场景、光影和自然运动。不过一旦画面里出现大量准确文字、排行榜、数据变化和复杂版式，结果就容易失控。

Remotion 就很适合制作这种**结构清楚、需要精确控制或者会重复使用**的动画，例如可视化数据、图表、复杂 UI、知识讲解等。

下面我们手把手走一遍：从安装、导出，到四种最典型的实战场景。

## 02 | 安装和导出

安装步骤很简单。

首先在 WorkBuddy 中选择一个本地空文件夹作为工作空间。再给 Agent 进行授权，对于可信任的任务，可以点允许完全访问。

然后把下面这段话发给它：

```
请从 GitHub 官方仓库 remotion-dev/skills，将 Remotion Agent Skills 全局安装到 WorkBuddy。
安装完成后，制作一个 5 秒的数字增长动画，并打开 Remotion Studio，确认可以正常使用。
```

<InfoCard title="前置条件">
Remotion 在电脑上运行需要 Node.js 和 npm。对于小白来说，通常不用去管这个，Agent 会自行判断并补齐所需环境。第一次创建 Remotion 视频时，安装运行环境和项目依赖会花一些时间，安装完成后后续使用通常会快很多。
</InfoCard>

等待一会儿之后，Remotion 工程就已经创建好了，官方提供的 12 个 Skills 也全部安装进了 WorkBuddy。同时，我们刚才要求生成的 5 秒数字动画也顺利跑出来了。

它会给你一个 Remotion Studio 的本地链接，直接点开跳转到本地浏览器中打开，也可以直接在侧边栏中预览。点开后就能看到这个数字跳动的动画效果了。

如果你想自由修改里面的文字、颜色、样式，可以直接在聊天框跟 AI 提需求。但如果改动很频繁，更高效的做法是直接说：我希望能够在 Remotion Studio 中自由修改数据。

如何导出呢？通常情况下，只需要在聊天对话框说一句"帮我导出"就 OK 了。如果要手动导出：点击右下角的 **Render**，视频编码选择 **H.264**，然后点击 Render video，导出的就是常规 MP4 格式的视频。

但很多时候，我们要的是**透明背景版本**的动画，这样可以把动画插入到任何剪辑工程文件中。

于是只需要跟 Agent 提需求说：保留现在的版本，再给我一个透明背景格式的版本。不一会儿，合成列表里就多了一个新的视频合成，它是去掉背景的版本。

要去掉背景，就得导出带透明通道的视频，四步完成：

1. 视频编码改为 **ProRes**
2. ProRes profile 选择第一个 **4444 XQ**
3. 图片格式改为 **PNG**
4. 像素格式选择最后一个 **yuva444p10le**

最后点击 Render video，就可以渲染视频了。导出之后，就可以把这个透明背景的动画素材叠加到自己任意视频中。

## 03 | 人物卡片动画

接下来我们测试一个更接近真实创作的场景。

很多历史、文学和知识类视频都会穿插人物介绍。有时只有短短几秒，里面却要同时处理**人物图片、姓名、朝代、身份、代表作和动画节奏**。人物一多，还要保证每张卡片的样式一致。

我准备先做一张李白的人物卡片。提前用 AI 做出一张李白的图片，放进当前 Remotion 工程，然后把下面这段话交给 WorkBuddy：

```
请在当前 Remotion 工程中新增一个 6 秒的历史人物卡片动画，人物为李白，我会提供人物图片。
画面使用深色背景和暗金色点缀，人物放在右侧，文字信息放在左侧。
依次显示"李白""唐代诗人""字太白，被后世誉为诗仙"和代表作《将进酒》《静夜思》，最后完整定格。
整体接近高质量历史纪录片中的人物信息卡，配合轻微的入场音效。
完成后打开 Remotion Studio 预览，保留已有动画。
```

经过一两轮的调整后，视频很快就做出来了。这张卡片已经包含**图片、文字层级、版式、动画和音效**。

Remotion 的好处在于，同一个 Remotion 工程中，可以不断复用之前的合成。假设还需要做一张杜甫的卡片，不用再重复描述配色和动画效果。

我们还可以继续做出更多卡片，最后直接让 Remotion 剪辑到一起：

```
请在当前 Remotion 工程中新增一个横版 16:9 的组合动画，把已经完成的李白、杜甫和苏轼三张历史人物卡片连接成一条完整视频。
开头增加一段约 2.5 秒的引导画面。沿用现有的深色背景、暗金色和米白色视觉风格。
画面中央出现文案"一卷诗书，遇见李白、杜甫与苏轼"，随后自然进入李白卡片。
保留三张人物卡片原有的入场、文字和人物动画。
苏轼卡片展示完成后进入结尾。苏轼卷轴先向中心收拢，随后在画面中央重新展开成一张更宽的横向卷轴。
李白、杜甫、苏轼三个人物从画面底部依次升起，李白在左侧，杜甫在中间，苏轼在右侧。
三个人物的大小、底部位置和视觉重量保持协调。人物下方分别显示姓名和简短标签：
李白 浪漫，杜甫 沉郁，苏轼 旷达。
三个人物全部出现后，在画面上方显现结尾文案"诗意跨越千年，依然与我们相遇"。
文案和人物全部出现后停留约 2 秒，再自然淡出。
```

## 04 | 知识讲解动画

大家应该看过很多科普类博主的视频，本身并不需要持续出现真人。画面通常由**口播、字幕、流程图、关键词卡片和少量实拍**组成。

Remotion 就很适合做其中的信息动画。它能够加入、剪辑和控制口播、音乐及音效，也能把 SRT 字幕导入后制作逐词高亮等字幕动画。

我准备做一段不超过四十秒的知识解释视频，主题是 **LLM、Agent、工具和 MCP 之间的关系**。

先把口播文案音频做出来，可以自己录，也可以用各类 TTS 等文本转语音的工具进行 AI 配音。做完之后发给 WorkBuddy，并且告诉它做好前面的准备工作：

```
这是一个 31 秒的口播音频。请先识别完整口播内容，生成带时间轴的字幕文件，
同时保留一份 Remotion 可以直接使用的字幕数据。
请先把识别出的完整文字和分段时间发给我核对，暂时不要开始制作视频。
口播文案为：
很多人经常把 LLM、Agent 和 MCP 混在一起。LLM 负责理解任务和生成内容，
Agent 会围绕一个目标，决定下一步做什么。要读取文件、搜索网页或运行命令，
还需要调用工具。API 和 CLI 是工具提供能力的常见方式，MCP 则给 AI 连接工具和数据
提供了一套更统一的接口。简单理解，用户把目标交给 Agent，Agent 调用 LLM 做判断，
再调工具把事情完成。
```

很快，它就严格对照口播音频做了逐字级时间戳识别。接着再输入下列指令：

```
字幕内容已经确认。请以这段约 31 秒的口播音频为唯一时间轴，在当前 Remotion 工程中
新增一条横版 16:9、1920×1080 的知识讲解视频。
这条视频需要做成视觉信息丰富的科普短片。画面不能只使用背景加字幕，也不要把整段口播逐句放大显示。
字幕只负责辅助阅读，主要内容需要通过卡片、动态图解、流程模块、图标、连线、数据变化、
模拟界面和代码生成的视觉特效来解释。
字幕放在画面底部安全区域，每次显示一到两行，可以对当前读到的关键词进行颜色强调。
画面中央只显示真正需要记住的关键词、术语和结论，不要重复展示完整字幕。
整体采用现代科技科普风格。使用深色背景、清晰的高对比文字和一到两种强调色。
卡片、图标、连线和模拟界面保持同一套设计语言。
人物说到关键词时，对应元素再出现、连接、展开或高亮。
```

初稿完成后，我们可以继续修改，也可以直接导出渲染。如果再插入一段自己的实拍或者数字人口播画面，最终效果会更有感觉。

## 05 | 暑期票房排行混剪

Remotion 还非常适合做一些作品展示类的混剪。甚至更方便的是，很多素材根本不需要自己去搜集和下载。

可以提前安装 Skill：yt-dlp downloader，WorkBuddy 中直接搜索并安装。之后每次要做视频，如果需要一些现成的影视或者网络热梗素材等，都可以直接调用这个 Skill 让它帮你下载和整理，相当方便。

即便你懒得装这个 Skill，直接输入相关指令，Agent 也会想办法给你安装调用的。

比如我要做暑期档电影票房排行的视频，直接输入下列指令：

```
请用 Remotion 制作一个"2026 内地暑期档电影票房 TOP 5"短视频。
16:9 横屏，时长控制在 22 秒左右。整体参考专业电影榜单和颁奖礼包装，
使用深黑、暗红和金色作为主色，画面有电影银幕、聚光灯和轻微胶片质感，
节奏紧凑，有冲击力但不要显得杂乱。
排行榜收集排名前五的电影，票房金额均为 2026 年 6 月 1 日至 8 月 31 日的内地暑期档票房。
请自行搜索并下载这五部电影的高清预告片或公开视频素材，每部选取几秒最有代表性的片段。
视频开头用约 2 秒展示标题"2026 内地暑期档电影票房 TOP 5"，
随后按照第 5 名到第 1 名依次揭晓。每部电影出现时，同时展示大型排名数字、
电影名称、票房金额和动态票房条，金额要有数字增长动画。
电影片段在背景中播放，文字区域增加暗色渐变，保证信息清晰。
结尾将五部电影同时整理成一张完整的横向票房柱状图，柱形长度按照票房金额比例显示。
添加一段有电影感、节奏逐渐加强的背景音乐，配合排名切换加入适量的低频冲击声和转场音效。
完成后检查影片名称、排名和票房数字是否准确，确保视频片段没有黑帧、变形或比例不一致。
打开 Remotion Studio 展示预览。
```

看到没有，指令一出，它先自己搜索影片信息，然后规划出要下载的影片素材，接着就着手安装下载工具 yt-dlp。

成片效果很不错：字幕包装到位，动效精致，音乐、音效都有。如果背景音乐不满意，你也可以发一首音乐给它，让它在剪辑的时候卡上点。

## 06 | 三维地图路线动画

地图动画在历史、旅行、商业、出海和新闻类视频里都很常见。简单路线可以用平面地图解决，涉及**地球转动、城市推进、地形飞越和建筑**时，制作难度会明显上升。

Remotion 能够接入高德、Mapbox、MapLibre、MapTiler 和 CesiumJS 等地图方案，若要做地球转动等效果也可以和 Three.js 结合。

如果要用到一些详细的地图图层数据，例如道路路况、卫星图、热力学图层等，就需要高德、Mapbox 等第三方的 API Key。涉及到省市轮廓边界的，可以去阿里云 DataV 下载 GeoJSON 或 SVG 数据。

我拿六个线下小伙伴的头像，做了一个从各自家乡来深圳的动效。效果比较简单，但我已经觉得非常惊艳了。

## 07 | 写在最后

以前，很多创作工具都有很高的专业门槛。想做动效要学 AE，想做复杂镜头还要接触三维软件。

对于大多数非从业者来说，光是学习成本就足以让人放弃。Agent 参与制作以后，这道门槛正在降低。越来越多的东西可以通过对话和代码来实现。

现阶段的 AI 还无法代替每个领域的专业能力，却已经可以帮助普通人迈出跨领域创作的第一步。

> 强的只是工具不是你。作品最终呈现成什么样，依然取决于创作者的审美、经验和每一次选择。

<SummaryCard title="带走清单">
- 结构清楚、需要精确控制的动画交给 Remotion，人物和光影交给生成式 AI
- 装好 Skill 后用自然语言提需求，Agent 自动补齐环境并编写动画代码
- 一段口播音频加字幕数据，就是知识讲解视频的完整时间轴
- 先做出东西，再慢慢形成自己的方法，积累真正属于自己的作品
</SummaryCard>

我们每次分享这些工具和玩法，是希望尽量减少一些信息差，让大家更快迈出第一步。
