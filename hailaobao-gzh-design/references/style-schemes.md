# Style scheme 目录

一共 7 套 scheme，每套是"主题色 + 版式 + 强调样式 + 组件皮肤"的整套预设。选一个就够，不要混搭。

**AI 必须只从下面的 `id` 里选。**渲染脚本收到未知 id 会报错。

---

## `jade-business` — 玉石商务

- **主题色**：翠绿 + 深墨
- **版式**：极简版（`minimalist`）—— 大量留白 + 序号引导
- **强调**：翠玉渐隐（`gradient / #CBE6D8`）
- **卡片**：顶部彩条，代码块偏终端

**适合**：方法论、工作复盘、深度分析、AI 观点类。

**不适合**：情感 / 生活 / 消费向文章 —— 会显得冷。

---

## `warm-editorial` — 暖色编辑部

- **主题色**：琥珀 + 深棕
- **版式**：杂志版（`editorial`）—— 大标题 + 分栏发丝线
- **强调**：均匀浅底（`soft-fill / #FDE68A`）
- **卡片**：牛皮纸质感，圆角

**适合**：人文、阅读、生活方式、复盘故事、餐饮旅行、书影音。

**不适合**：技术、代码、数据密集。

---

## `mono-tech` — 极客单色

- **主题色**：黑白 + 单一鲜色
- **版式**：紧凑版（`compact`）—— 信息密度高、贴合小屏
- **强调**：纯加粗（`plain-bold`）
- **卡片**：直角边、无阴影

**适合**：技术文章、命令行工具、开源项目、bug 复盘、架构说明。

**不适合**：情感 / 品牌 / 消费类。

---

## `champagne-brand` — 香槟品牌

- **主题色**：香槟金 + 米白
- **版式**：优雅版（`elegant`）—— 衬线 + 大号 kicker
- **强调**：渐隐标记（`gradient / #F2DFB0`）
- **卡片**：柔角、金线

**适合**：品牌宣发、产品发布、高端消费、活动预告、机构公告。

**不适合**：技术、复盘、日常记录。

---

## `mist-notebook` — 雾霾笔记

- **主题色**：雾霾蓝 + 深灰
- **版式**：手账版（`notebook`）—— 淡网格底、彩色标签
- **强调**：半高光带（`light-band / #C9D9EA`）
- **卡片**：便签质感

**适合**：学习笔记、干货清单、教程分步、随笔感悟、亲子育儿。

**不适合**：严肃财经、法律、宏观分析。

---

## `midnight-report` — 午夜研究报告

- **主题色**：深靛蓝 + 冷灰
- **版式**：极简版（`minimalist`）—— 深色底，反色排版
- **强调**：强调色下划线（`underline / #7AB0F0`）
- **卡片**：低亮度、蓝调阴影

**适合**：数据分析、行业观察、事件复盘、投研报告、财经速评。

**不适合**：轻松生活、情感故事。

---

## `forest-demo` — 森绿演示

- **主题色**：森绿 `#255E4A` + 标题底 `#F1F4F3`
- **版式**：演示版 —— 编号徽章叠在浅色标题条上，徽章圆角 `3px 14px 3px 14px`，右侧一条短装饰线
- **强调**：纯加粗
- **卡片**：森绿描边；提示词代码块是深色终端窗口，顶栏三点 `#FF5F57` / `#FFBD2E` / `#28C940`

**适合**：工具教程、案例演示、Agent 提示词实录。视觉来自 WorkBuddy + Remotion 那篇公众号演示文。

**不适合**：情感故事、品牌软文、需要暖色或整页深色底的长文。

## 匹配决策速查

| 用户文章类型 | 首选 scheme | 备选 |
|---|---|---|
| 方法论 / AI 观点 / 工作流程 | `jade-business` | `mono-tech` |
| 教程 / 命令行 / bug fix | `mono-tech` | `mist-notebook` |
| 工具教程 / 案例演示 | `forest-demo` | `jade-business` |
| 心得 / 复盘 / 阅读笔记 | `warm-editorial` | `mist-notebook` |
| 产品发布 / 活动 / 品牌 | `champagne-brand` | `warm-editorial` |
| 学习笔记 / 干货清单 | `mist-notebook` | `jade-business` |
| 行业分析 / 数据 / 财经 | `midnight-report` | `jade-business` |

如果没把握，默认走 `jade-business` —— 它对绝大部分文字类内容都能兜底。
