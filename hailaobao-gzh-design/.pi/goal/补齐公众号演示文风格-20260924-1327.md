## Goal

把微信文章《我挖到 WorkBuddy 一个神仙玩法》的演示结构和视觉语言补进 `hailaobao-gzh-design`，并修掉其他工具已改内容里对不上的地方。现有 6 套风格保持原样；这篇文章的深绿标题条、编号徽章和终端提示词窗口成为一套可选用的新风格。演示样例仍用已有的改写稿，不把原文整篇再抄进来。

## Acceptance criteria

1. `scripts/schemes.mjs` 导出 7 个 scheme id。新 id 写进 `references/style-schemes.md`，`node scripts/typeset.mjs --scheme <新id> --input examples/remotion-demo.md --out examples/remotion-demo.html` 退出码为 0；`--scheme not-a-scheme` 退出码非 0。
2. 用新 scheme 渲染出的 `examples/remotion-demo.html` 同时包含这些原文视觉标记：主色 `#255E4A`、标题底 `#F1F4F3`、编号徽章圆角 `3px 14px 3px 14px`、提示词块三点色 `#FF5F57`、`#FFBD2E`、`#28C940`。顶栏方案名不是「玉石商务」，页面仍有「复制到公众号」按钮。
3. 用 `jade-business` 渲染 `examples/demo.md` 的 HTML 仍含 `#059669`，且不含 `3px 14px 3px 14px` 和 `#FF5F57`。
4. `SKILL.md` 工作流步骤为连续的「步骤 1」到「步骤 5」，不再从步骤 2 跳到步骤 4。`SKILL.md`、`AGENTS.md`、`references/style-schemes.md` 里写明的风格数量与 `schemes.mjs` 的 id 数量一致，且都指向新 scheme。
5. `references/demo-article-patterns.md` 把样本源文的 `#255E4A` / `#F1F4F3` 映射到新 scheme id，不再写成 `jade-business`。

## Boundaries

- 不改现有 6 套 scheme 的配色和组件几何，不改它们的 id。
- 不把微信原文整篇粘贴进仓库，不新增原文没有的观点；演示载体继续用现有 `examples/remotion-demo.md`。
- 不改 `skills_collection` 里其他 skill，不提交 git。
- 不增加 npm 依赖，渲染仍只靠 Node 内置模块和现有 `typeset.mjs`。
