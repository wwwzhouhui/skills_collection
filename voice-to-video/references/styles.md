# 风格目录（kits/）

每套风格是一个独立的 kit CSS，**组件契约与 `assets/kit.css`（BlockFrame 默认）完全一致**——同样的类名、同样的引擎，换一个 `<link>` 就换风格。引擎与动画机制和风格解耦，任何风格下 data-anim / SUBTITLES / 时间轴对齐规则都不变。

## 使用方法

合成页里把样式链接换成选中的 kit（相对路径从项目目录算，kit 文件从技能 assets/kits/ 拷贝到项目目录）：

```html
<link rel="stylesheet" href="kit-ink.css">   <!-- 例: 国潮水墨 -->
```

## 选择规则（用户未指定时按题材自动匹配）

1. 内容关键词含 AI/代码/工具/互联网 → `dark-hud` 或默认 BlockFrame；
2. 教程/命令行演示为主 → `terminal`；
3. 历史/财经/深度长文解读 → `editorial`；
4. 教学/给新手讲概念 → `whiteboard`；
5. 商业分析/观点输出 → `swiss`；
6. 传统文化/历史故事（中文语境）→ `ink`；
7. 拿不准 → 默认 BlockFrame（最稳）。

## 版式 DNA（各风格的内容结构差异 —— 必读）

**只换 kit CSS 是"换皮"，不达标。** 每种风格必须用不同的**场景编排方式**重写合成页：布局骨架、信息排布、装饰元素、动效签名都要跟着风格走。以下是各风格的版式配方（场景切分与时间轴对齐规则不变，仍按 timeline.json）：

### editorial 编辑杂志风 —— 杂志跨页
- 版面=对开跨页：超大衬线标题偏一侧 + 窄栏正文，非对称；细分隔线(1px)划分区域
- 要点用**双栏索引表**(编号+底线)，不用圆点卡片；重点句做**大引号拉引(pull-quote)**
- 巨大期刊数字(VOL.01/期号)当图形元素；页脚做脚注行；结尾页=版权页(colophon)
- 动效签名：fade/wipe 缓慢优雅，dur 600-900，像纸面展开；单场景红色≤1处

### terminal 终端极客风 —— 全程一场终端会话
- 每个场景= **命令 → 输出** 结构：`$ 命令`(用 data-anim="type" 打字机) + 输出行逐条 fade
- 列表做成 `ls`/日志行(`[OK]`/`✔`/`drwxr-xr-x`)；对比用 `$ diff` 双栏；步骤做成 `[1/6]…[6/6]` 进度行
- 大标题=大号 mono 注释/横幅；光标闪烁用 HF.on 按 t 取模(确定性)，禁 CSS animation
- 动效签名：type(打字) 为主 + 短 fade；一切文字化，无图形卡片

### whiteboard 手绘白板风 —— 板书逐步填满
- 便利贴(彩色方块+旋转±2-4°+胶带条)、手绘圈(椭圆 wobble 边框圈住标题)、箭头用 → ↓ ↷ 字符
- 清单=手写 checklist，逐条打勾(✓ 用 pop 弹出)；命令放"手写便签盒"里
- 关键词用**马克笔圈+下划线**强调；元素像被人一笔笔写上去(type + wipe-l)
- 动效签名：pop(盖章感) + type(手写) + wipe-l(画出)；组件旋转制造手工感

### swiss 极简瑞士风 —— 模数网格版式
- 一切贴**可见网格**：文字齐边平铺(左上对齐)、细分隔线分栏，无卡片无底色块
- 巨大数字/单词当图形主体(占 1/3 版面)；清单=基线对齐的编号表格(01/02/…+底线)
- 每场景红色只出现一次(高亮块或词)；信息密度可以高，但留白分区要严格
- 动效签名：快而脆(fade dur 120-200 / up 300)，像排版被"拍"上去；绝不用 pop 弹跳

### ink 国潮水墨风 —— 竖排·印章·界格
- 标题可**竖排**(`writing-mode:vertical-rl`)，两栏竖排=对联式布局；阅读顺序右→左
- 印章(红底白字方章)做标签/序号；要点编号用汉字(一二三…)；卡片可用圆形"月洞窗"(border-radius:50%)
- 分隔用墨色渐变细线(横细线 gradient 透明→墨→透明)；结尾像卷轴收尾
- 动效签名：fade 缓慢(dur 700-1000)如墨晕开 + pop(钤印感, data-ease="back" 轻微)；字距放宽

### glass 玻璃拟态 —— 悬浮玻璃层
- 背景=固定的极光色场(多组 radial-gradient 色斑，写进 #stage 背景即可)；一切内容浮在**磨砂玻璃面板**上
- 卡片/标签/字幕条都是半透明白 + `backdrop-filter: blur()`；圆角大(20px+)；层级靠透明度和投影区分
- 布局偏居中英雄式+左右浮层；标题可用渐变文字(background-clip:text)
- 动效签名：fade/up 柔和(dur 500-700)、pop 轻微(ease back 不过冲)；无硬边、无纯色大色块

### clay 黏土拟态 —— 软胶玩具
- 一切元素**蓬松凸起**：同色系底 + 双层阴影(外投影 + inset 白高光/暗内缘)，无描边无锐角
- 胶囊形(999px 圆角)标签和按钮；圆形徽章当序号；要点装进胖圆条里
- 颜色高饱和粉彩；重点词用粗马克笔底纹
- 动效签名：pop(ease back, 过冲明显)像捏下去回弹；列表逐条"落下"(up + back)

### blueprint 蓝图工程风 —— 工程图纸
- 深蓝底 + 白色制图网格(细格 24px/粗格 120px 两层)；内容区有图框，场景角部放"+"规线
- 卡片=虚线框 + 右上角 `FIG.` 图号标签(kit 已实现，配 `data-fig="1 "` 使用)；清单编号用 `⌀1⌀2` 气泡
- 对比/原理场景用标注式布局：引出线、尺寸记号、NOTE 注释块；文字多用 mono
- 动效签名：fade + wipe(像图纸展开描图)，dur 300-500，干脆利落；强调色只用琥珀黄一处

### pixel 像素复古游戏风 —— 8-bit 游戏 UI
- 一切装进**游戏对话框**：粗 4px 黑边 + 8px 硬投影；标题带红/黑双层错位投影
- 清单用任务列表(☐→☑，kit 有 .quest)；进度/数据用**分段血条**(.xpbar)表达；页眉是 SCORE 计分区
- 序号用 ★/▸/关卡徽章；结尾可做 "PRESS START / STAGE CLEAR" 式谢幕
- 动效签名：pop 硬弹(dur 250-350 无缓出拖尾)、fade 瞬切(120-180)；全部 mono 字体

### stage 深蓝舞台风 —— Remotion 同美学发布会
- 每个能力的画面装进一张**大圆角深蓝面板**(`.panel`, 约 1660×720 居中)；深夜蓝底 + 极淡网格 + 中心暗角
- 三件套布局：左上节号标题(`.secno` 渐变数字 + 标题/副标题) / 底部居中面包屑(`01 · 数字滚动`) / **面板底部细进度线**(`.pline`，随本场景进度生长，用 HF.on 闭包驱动)
- 强调 = 浅蓝→紫渐变(`.gtext` 渐变大词、`.pill.on` 药丸切换、`.big-num` 发光数字)；影视/数据段切换金色(`.hl-coral` `.gtext-gold`)
- **面板内嵌视频**：`HF.bindVideo("#vid", 场景start)` + render.py `--wait-videos`，素材**必须 webm(VP9/VP8)**——无头 Chromium 无 H.264 解码器
- 动效签名：fade/up 从容(dur 400-600)、count 上滚是招牌；场景间黑场过渡自然发生(面板内容切换即可)

## 各风格注意点

- **dark-hud**：发光用 text-shadow/box-shadow 实现，纯 CSS 无粒子图；深底上正文对比度足够（#E6F1FF on #0A0F1E）。
- **editorial**：标题衬线（Georgia/思源宋体回退宋体）；强调色克制，一屏最多一处红。
- **terminal**：全套等宽字体，中文也走 mono 回退；`.hl-*` 是变色发光而非底纹。
- **whiteboard**：手写体回退链 `Segoe Print → Comic Sans MS → 楷体`；组件带轻微 rotate（±1.2° 内）制造手写感，确定性不受影响。
- **swiss**：无边框圆角（0）、无阴影；强调红一屏一处；编号用 CSS counters（`01 / 02 /`）。
- **ink**：楷体标题/宋体正文（Windows 自带 KaiTi/SimSun，无需装字体）；kicker 是印章样式；`#stage::after` 画界格内框。
- 全部风格：字幕条/进度条/播放提示都有对应皮肤，逐词卡拉OK高亮色随风格走。
- stage：内嵌视频素材**必须转 webm(VP9/VP8)**（`ffmpeg -c:v libvpx-vp9`）——Playwright 的 Chromium 无 H.264 解码器，mp4 会 readyState=0 黑屏；渲染时加 `--wait-videos`；预览时 `HF.bindVideo` 注册的片段会跟随音频时钟播放。
- glass：磨砂用 `backdrop-filter: blur()`，无头 Chromium 支持且确定性可截图；色场背景是静态渐变，不引入图片。
- clay：立体感全靠 box-shadow 双层(外投影+inset 高光)，无渐变图片；文字对比度已调足。
- blueprint：卡片图号用 `data-fig="1 "` 属性显示；强调色只有琥珀黄，其余全白线。
- pixel：未装像素字体，用 mono 加粗+双层错位文字投影近似 8-bit 感；.quest/.xpbar 是 kit 内置组件可直接用。
