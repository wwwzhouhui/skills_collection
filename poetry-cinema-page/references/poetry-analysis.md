# Poetry analysis and scene mapping

## Preserve the text

Keep the user's wording and punctuation in visible quotations. Check the conventional text before writing interpretation. If the user supplies a known variant, retain it and note the common alternative only when it changes meaning or pronunciation.

## Segment by dramatic function

Create 5–8 beats. Start a new beat when one of these changes:

- viewpoint or spatial scale;
- time, season, or lighting;
- present reality versus memory/imagination;
- speaker, historical figure, or focal object;
- emotional direction;
- rhetorical mode: description, action, reflection, release.

Do not force every line into a separate image. Closely related lines should share one scene.

## Beat record

For each beat record:

| Field | Purpose |
|---|---|
| original | Exact line(s) shown prominently |
| literal | Clear modern-language meaning |
| images | Concrete visible nouns and actions |
| technique | Contrast, allusion, montage, verbs, sound, metaphor, etc. |
| emotion | What changes for the reader here |
| scene | A filmable, historically plausible composition |
| copy side | Left or right negative space required in the image |

## Explanation standard

- Lead with concrete language understandable to a general reader.
- Explain why a word matters, not merely what it means.
- Connect imagery to emotion without declaring every object a fixed symbol.
- Distinguish the historical person/place from the poet's imaginative reconstruction.
- Include genre context only when it helps the reading.

## Closing analysis

Cover four layers:

1. form: poem/ci/qu, tune pattern, stanza structure;
2. image system: repeated spaces, objects, seasons, light, sound;
3. movement: how the poem travels through space, time, and emotion;
4. central tension: home/tianya, hero/self, permanence/change, union/separation, etc.

Avoid inflated claims such as “the greatest ever” unless presented as a sourced historical reception statement.
