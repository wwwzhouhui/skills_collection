# 提示词结构

深度提示词工程（运镜词典、特效复刻、短剧台词设计等）用 `seedance-prompt-zh` / `seedance-prompt-en`。本文只给**能直接跑通接口**的结构和模板，以及图和视频之间的衔接规矩。

## 通用规则

- 中文英文都支持；2.5 额外支持西/葡/日/韩/印尼/马来/泰/阿/越语。
- 建议长度：中文 ≤500 字，英文 ≤1000 词。超了模型会丢细节，不是报错。
- 引用素材写成 `@图像1` `@视频1` `@音频1`（老写法 `@图片1` 也认），并且在句子里**说明它用来干什么**——只说"参考@图像1"等于没说，要说"参考@图像1 的人物形象"。
- 台词用双引号包住，模型更容易分清"说的话"和"画面描述"。
- 时长 ≥10s 时按时间段拆写，控制力明显更好。

## 文生图提示词（Seedream）

```
[主体 + 外观细节] + [动作/状态] + [场景与环境] + [光线] + [镜头语言：景别/焦段] + [风格与质感]
```

例：

```
28岁亚洲女性，黑色短发，深灰西装，站姿侧身回头
双手插兜，风衣下摆被风吹起
雨夜霓虹街道，地面有积水反光
冷蓝主光 + 紫红边缘光，逆光轮廓
中景，85mm 浅景深，背景虚化成光斑
电影质感，胶片颗粒，高对比度
```

要点：
- **景别和光线写清楚**，这两项对出图质量影响最大。
- 要当视频首帧的图，末尾加一句"构图保留运动空间/中景/轻微留白"。
- 多图参考时按 `@图1 @图2 @图3` 顺序在提示词里点名，并与数组顺序一致。

## 图生视频提示词（Seedance）

```
[首帧里已有什么，一句话确认] + [主体动作细节] + [镜头运动] + [光影/环境变化] + [时间节奏] + [声音]
```

例：

```
画面中的人物保持不动，先眨眼，再缓缓抬头看向窗外
镜头缓慢推近至面部特写，速度慢、匀速
窗外雨滴沿玻璃滑落，室内暖光在脸上轻微移动
前3秒安静，后2秒远处传来雷声
环境音：雨声、室内低频，无人声
```

要点：
- 首帧已经决定了"是什么"，提示词只需要回答"动什么、怎么动"。
- 动词具体化：不写"她很难过"，写"她抿嘴、眼神下垂、肩膀塌下来"。
- 镜头运动一次只给一个主运动，堆三个运镜等于让模型乱猜。
- 要人声就写台词并加双引号；不要声音记得把 `generate_audio` 关掉。

## 参考生视频（全模态）

```
参考@图像1 [用途]，参考@图像2 [用途]，参考@视频1 [运镜/动作/节奏]，音频参考@音频1
[本片自己的内容描述：主体 + 动作 + 场景 + 镜头]
```

用途清单，照抄不踩坑：

| 想控制什么 | 写法 |
|---|---|
| 人物长相 | `参考@图像1 的人物形象` |
| 服装 | `穿着@图像2 的服装` |
| 场景 | `场景参考@图像3` |
| 产品外观 | `产品细节参考@图像4` |
| 运镜 | `参考@视频1 的运镜` |
| 动作编排 | `参考@视频1 的动作` |
| 节奏 | `视频节奏参考@视频1` |
| 转场/特效 | `完全参考@视频1 的转场` |
| BGM | `背景音乐参考@音频1` |
| 音效 | `音效参考@音频1` |

## 分时段写法（10s 以上）

```
0-3秒：<开场画面、镜头位置、动作起点>
3-7秒：<动作发展、镜头运动>
7-12秒：<高潮或关键动作>
12-15秒：<收尾、定格>
```

每段只写该段时间内**新增**的内容，不要把整段重复描述三遍。

## 编辑 / 延长提示词

编辑（`task_type=edit`）——必须出现"编辑/替换/增加/删除"这类词：

```
编辑视频：把女主的外套从白色替换成深红，其余人物动作、镜头、背景保持不变
```

延长（`task_type=extend`）——必须出现"延长/续写"，并交代接哪一段：

```
向后延长5秒：镜头继续跟随人物走向门口，光线逐渐变暗，结束时停在门把手特写
```

延长时 `duration` 填**新增**时长，不是总时长。

## 常见失败与修法

| 现象 | 原因 | 改法 |
|---|---|---|
| 人物在镜头里换了脸 | 只给了一张参考图且没说明用途 | 明确写"参考@图像1 的人物形象，保持五官不变"；必要时补正脸+侧脸两图 |
| 动作僵硬/原地不动 | 提示词只有形容词 | 换成可见的动作动词，加点时间顺序 |
| 镜头乱飞 | 一次给了多个运镜 | 砍到一个主运动 |
| 画面糊、细节崩 | 字数超限或塞了太多并列要求 | 压到 500 字内，只留对结果影响最大的 3–5 件事 |
| 编辑任务报 TaskTypeMismatch | 提示词没有"改/换/删"的意图 | 加"把 X 改成 Y""删除 X"等明确指令词 |
| 出图和视频比例对不上 | 图用默认尺寸出的 | 出图就把比例定死，再进图生视频 |
| 音轨莫名其妙 | `generate_audio` 默认 true | 不需要声音时显式关掉 |
