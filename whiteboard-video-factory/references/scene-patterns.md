# 版式套路（坐标可直接抄，来自已出的两期）

画布 1920×1080，`CX = 960`。所有 y 底边 < 960。**右上角 x≥1600、y≤130 是品牌水印区，别放元素。** 大标题色优先 `C.brand`（品牌绿），需要对比时再用蓝/紫/橙。

## A. 开场：大标题 + 副标 + 三个对比物

```js
s.text(CX, 60, '薄肌', { size: 140, align: 'center', color: C.green });
s.text(CX, 240, '现在最流行的身材词', { size: 44, align: 'center', color: C.gray });
// 三个贴纸横排 x = 420 / 960 / 1500，y = 390，h = 370；标签在 780/860
s.image(420, 390, 'figure-thin', { h: 370, align: 'center' });
s.text(420, 780, '瘦', { size: 64, align: 'center', color: C.gray });
s.text(420, 860, '没肉', { size: 36, align: 'center', color: C.gray });
s.ellipse(750, 350, 420, 410, { stroke: C.green, strokeWidth: 3, strokeStyle: 'dashed' }); // 圈出中间那个
```

变体（Grok 期）：左贴纸/机器人 + 右侧大字标题 `s.text(800, 330, 'Grok Bot', { size: 150 })` + 灰色副标 y=510；下方 `≠` 对比 + 红色波浪线 `s.squiggle(880, 1390, 830)`。

## B. 左右对比：标题 + 中线 + 两列

```js
s.text(CX, 60, '薄肌 vs 厚肌', { size: 90, align: 'center' });
s.line([[CX, 200], [CX, 940]], { strokeStyle: 'dashed', stroke: C.gray });
// 左列：栏题 480/200，贴纸 (480, 300, h 380)，三条要点 x=280 y=700/760/820（size 40），箭头+结论 y=880~950
// 右列：同样，x 偏移 +960
// 点睛：两个圈注 ellipse(680, 830, 200, 110) + text(780, 850, '堆量', size 64)
```

## C. 三栏卡片（三要素 / 三能力）

```js
const colW = 540, gap = 60, top = 230;
const cx0 = CX - colW - gap, cx1 = CX, cx2 = CX + colW + gap;
s.rect(cx0 - colW / 2, top, colW, 720, { round: true, fill: C.fYellow, fillStyle: 'hachure', roughness: 1.2 });
s.text(cx0, top + 20, '① 体脂低', { size: 56, align: 'center', color: C.orange });
// 卡内：图标 top+120~300，主文案 top+230/300（size 44），灰注释 top+440/500（size 36），底部结论 top+620~660
```
每栏一个 beat；颜色 黄/紫/绿 或 黄/绿/蓝。

## D. 云端/中心图 + 三个下游

```js
s.cloud(CX, 300, 760, { fill: C.fBlue });            // 云 y 91~509
s.laptop(CX - 130, 220, 1.0); s.robot(CX + 170, 250, 0.55, { headOnly: true });
s.text(CX, 545, 'Bot 自己的云端电脑', { size: 44, align: 'center', color: C.blue });
// 三个下游盒子 x = CX-470 + i*380，y=650，220×90；箭头从 (CX-260+i*260, 610) 到 (x+110, 645)
// 左下角配角（月亮 + 24/7），右侧人物 + 红箭头审批
```

## E. 清单 / 场景列表

中间放主体贴纸或机器人（CX-100, 330），七个 `s.checkbox` 分左右两列 x=220 / 1360，y=260/420/580，第七个居中 (790, 720)。底部红色总结 + 波浪线 y≈850/930。

## G. 两步公式 / 有氧（图标 = 公式）

左：时钟 `clock(420, 470, 130)` + 橙色数字 y=640 + 灰注释 720；中 `=`(700,450,size 90)；右黄色卡 (800,400,460×160)；最右一列图标+词（快走/慢跑/水波/自行车贴纸），底部蓝色金句 y=880 + 波浪线 945。

## H. 总结页

- 公式：三个彩色盒子 + `+` `=` + 大字结论（y=260~380）。
- 中段两行金句 size 64（y=520/620）+ 灰虚线 720。
- 结尾问题 size 52~56（y=820）+ 黄色椭圆"评论区聊聊"(1500,780,240×110)。

## I. 封面（coverLayout 已固化，这里记文案套路）

- 4:3：左上黄标签 → 两行通栏大标题（第二行绿字 + 黄色马克笔，字号 ≈170）→ 灰副标 → 主角贴纸右下 h≈500 → 左下品牌标。
- 竖版：顶部标签 → 两行标题居中 → 副标 → 贴纸居中 h≈620 → 底部品牌标。
- 文案：第一行"谁/什么"（杜兰特随手一投 / 薄肌是什么），第二行反差或结论（赚得比打球多 / 三个月能练出来）；数字放副标。
- 杜兰特期：`title: '杜兰特随手一投\n赚得比打球多', sub: '25 万 → 6000 万，Hugging Face 这笔账', sticker: 'basketball-player'`。
