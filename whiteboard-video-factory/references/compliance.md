# 合规自查（发布前逐条勾完）

知识类账号的通用红线，按你的账号需要增删。

1. **主角是事 / 公司 / 现象。** 讲公众人物只讲公开商业事实（投资、合同、公开数据），标题让事件或公司做主语，人名放后半句或简介；不碰活人的塌房、丑闻、私德、慈善争议，标题里不出现"翻车 / 塌房 / 骗 / 割韭菜 + 人名"。
2. **估算与质疑有标注。** 只讲已公开报道；质疑用"据报道 / 被质疑 / 舆论认为"；估算值标"估算"。
3. **无投资建议措辞。** 不写"必赚 / 稳赚 / 抄作业 / 建议买入"；结尾问"你会不会"，不问"该不该买"。
4. **AIGC 标注。** 本 skill 的画面与配音都由 AI 生成，抖音要求这类内容标注来源（模板里已带「内容由 AI 生成」一行），其它平台按各自发布页的声明项处理。

**绕行区**：政治、宗教、民族、司法未决、灾难伤亡、未成年人。

白板讲公众人物时尤其注意第 1 条：标题让事件或公司做主语。
