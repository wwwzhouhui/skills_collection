## 小红书

**一句话做一条视频，我可能真的把剪辑师省掉了**

以前做一条视频的流程：
写脚本 → 找素材 → 配音 → 剪辑 → 加字幕 → 导出，一天没了。

现在：
1. 给一张自己的 IP 形象图（锁住角色一致性）
2. 写一段大白话逐字稿（不用写分镜）
3. 说一句「出片」

剩下的它自己干：
拆镜头 ✓ 配音 ✓ 字幕 ✓ 动画课件 ✓ 渲染成片 ✓

关键差别是从「抽卡」变成「可控」——每一帧都能改，字幕时长、动画节奏、转场方式全都算得出来，不满意不用重新抽，改一行重渲就行。

56 秒 / 6 个分镜 / 不到 100 积分 / 横竖屏双版本
